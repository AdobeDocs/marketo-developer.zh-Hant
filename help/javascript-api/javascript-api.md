# Javascript API

Marketo使用者端JavaScript整合提供銷售機會追蹤、表單、網頁個人化和預測性內容功能。 您必須擁有Marketo帳戶才能使用這些功能。

實作通常會新增內嵌程式碼至Web屬性。 您也可以呼叫內嵌程式碼公開的JavaScript函式以新增功能。

內嵌程式碼是您的Marketo例項唯一的，因為它包含帳戶識別碼。 在Marketo使用者介面中，前往適當的面板，將內嵌程式碼複製到剪貼簿，然後貼到網頁中。

## 銷售機會追蹤(Munchkin)

Marketo的[Munchkin JavaScript追蹤代碼](lead-tracking.md)會從造訪您的網站中產生潛在客戶。 它也會追蹤尚未提供個人資訊的訪客，並建立包含使用者IP位址和其他資訊的匿名銷售機會。

在Munchkin的「管理員」區域中，於Munchkin頁面上設定Marketo。

## Forms 2.0

[Forms 2.0](forms-api-reference.md)可讓行銷人員在不具備程式設計知識的情況下建立網路表單。 Forms可位於Marketo登陸頁面上，或內嵌在您的網站任何頁面上。

使用Forms 2.0 JavaScript API來擴充Marketo網路表單的核心功能。

## 網頁個人化

[Marketo Web Personalization](web-personalization.md)可協助您根據潛在客戶的身分和行為，即時與網站上的潛在客戶互動。

## 預測內容

[Marketo預測性內容](predictive-content.md)使用機器學習和預測性分析來向網頁訪客呈現相關內容。 將文字說明和影像新增至您的內容，並將多個內容建議內嵌至您的網站。
